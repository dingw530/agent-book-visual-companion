# Agent Book Visual Companion

《深入理解 AI Agent》章节知识图解。项目把书中的核心概念、流程和关系整理成图，方便复习和交流。

本项目是读者独立制作的学习辅助材料，与作者及原书出版方无隶属关系。图解用于帮助理解，不能替代原书。书籍内容及相关权利归原作者和其他权利人所有。部分插画由 ImageGen 协助生成，章节要点依据原文整理。

## 原书

李博杰：《深入理解 AI Agent：设计原理与工程实践》

- [原书及配套代码仓库](https://github.com/bojieli/ai-agent-book)
